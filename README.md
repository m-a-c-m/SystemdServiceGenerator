# systemd Service Generator — Free Online Tool

**systemd Service Generator.** Generate production-ready systemd unit files with restart policies and non-root users. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/systemd-service-generator](https://miguelacm.es/tools/systemd-service-generator)

## ✨ Features

- **⚙️ Complete units:** [Unit], [Service] and [Install] sections with the directives that matter.
- **♻️ Restart policies:** on-failure/always with configurable RestartSec delay.
- **🔒 100% private:** Units are composed locally in your browser.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/SystemdServiceGenerator.git
cd SystemdServiceGenerator
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/systemd-service-generator
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/systemd-service-generator
```
